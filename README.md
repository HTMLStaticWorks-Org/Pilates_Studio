# FORME Pilates Studio — Complete Multi-page Website

## Pages included
- `index.html` — Home 1: classic consumer homepage
- `home-2.html` — Home 2: premium / private studio homepage
- `about.html` — studio philosophy and approach
- `classes.html` — class formats and class descriptions
- `instructors.html` — instructor profiles and credential placeholders
- `membership.html` — three membership plans and FAQs
- `amenities.html` — studio equipment and amenities
- `contact.html` — contact details placeholders and enquiry form
- `dashboard.html` — member dashboard UI
- `login.html` — member login UI
- `signup.html` — member registration UI

## Shared assets
- `styles.css` — shared design system and responsive styles
- `script.js` — hamburger navigation and demo form interactions

## Run locally
Extract the ZIP and open `index.html` in a modern browser. No build step or package installation is required.

## Responsive layout and navigation
- Designed to reflow from 300px mobile widths through desktop.
- Hamburger navigation is enabled through 1100px, including tablet widths.
- Desktop navigation appears above 1100px.
- Menu supports open/close, closes after navigation, closes with Escape, and closes when resizing to desktop.
- Forms display demo confirmation messages; they do not send or store data.

## Important production setup
This is a complete front-end website prototype, not a connected production booking platform.
Before launch:
1. Replace placeholder studio address, phone, email, instructor names and credentials with verified information.
2. Confirm actual membership prices, pack expiry, cancellation policy, class schedules and availability.
3. Connect enquiry forms to an email service, CRM or backend.
4. Implement authentication, authorization, member data storage and secure session management.
5. Connect class bookings, waitlists, cancellations, pack balances and billing to a scheduling/payment backend.
6. Review privacy, accessibility, medical-scope and legal content.
7. Replace remote Unsplash demo photography with licensed, studio-specific images.

Images and Google Fonts load from external services and require an internet connection.
